# 版本与实验环境（建议冻结基线）

> 版本盘点日期：2026-10-09。下表是课程准备采用的候选锁定组合，不代表这些组件已在同一套机器上完成集成测试。发课前必须完成冒烟测试、保存实际镜像摘要和包清单；没有通过验证的可选栈不得写成“已验证环境”。

### 版本锁定规则

1. **锁的是组合，不是单个“最新版”。** 内核与 `perf`、Rook 与 Ceph/Ceph CSI、snapshot CRD/controller 与 CSI snapshotter 必须按表中的组合验证。确需替换其中一项时，要重新核对上游兼容矩阵并重跑受影响实验。
2. **包管理器也要锁。** 用 [Ubuntu Snapshot](https://snapshot.ubuntu.com/) 的固定时间戳构建环境镜像，将实际快照 URL、ISO SHA-256、`dpkg-query -W` 输出和安装命令纳入课程发布物。安全更新触发重建时，生成新的锁定日期并回归测试，而非无期限保留有漏洞的旧包。
3. **源码锁到 tag 和 commit。** SPDK 等含 submodule 的项目保存 `git rev-parse` 与 `git submodule status --recursive`；不从 `main`、`master` 或 `latest` 拉代码。
4. **容器锁到 digest。** 版本 tag 用于可读性，实际发布清单需写成 `image:tag@sha256:...`。Rook 组件以其版本化 `images.txt` 为来源，不单独覆盖 sidecar。
5. **语言依赖需有 lockfile。** 若后续课程加入 Python/Go/Java 代码，固定解释器/SDK 和传递依赖（如 `uv.lock`、`go.sum`、Maven/Gradle lock）；不要只写一个最低版本范围。
6. **实验数据也属于版本。** 固定数据集来源/校验和、生成器版本、随机种子、工作负载文件、设备型号与固件、队列深度、容器资源限额。硬件不能被软件版本号替代。

### 不应假装可以固定的对象

- AWS S3 等托管服务端由供应商持续更新，无法在课程侧固定其构建号。锁客户端、区域、API 操作、测试脚本和核验日期；RGW 用对应的 Ceph 镜像版本，并明确其兼容边界。
- SSD 的 FTL、垃圾回收及固件行为依赖具体设备；主线只用模型/模拟，实机选修须记录设备型号、固件和 namespace 配置。
- NVMe、S3 等标准应记录所引用的规范版本/章节；标准文本不是可安装的软件依赖。
- 性能数字不能只靠版本复现，还须记录硬件、内核、文件系统、缓存状态、负载、重复次数和误差。

- **M09 必做路径：**使用 [Lab 09 本地故障域/副本/重建压力模拟](../labs/lab-09-ceph-failure-simulation/README.md) 和标准库测试；不连接 Ceph，不要求 root、集群或真实设备，不触碰真实数据。Ceph 部署是纯选做，不是本课程默认部署实验。

## 推荐实验分层

1. **基础层（默认）：**Ubuntu 24.04.5 LTS 普通主机或虚拟机；优先使用临时目录、普通文件、容器和生成的小型数据集。核心课程不需要裸盘写入或云资源。SSD FTL/垃圾回收/写放大实验使用概念模型、合成轨迹或模拟器；ZNS/FDP 真机能力属于选修，不把特定 SSD 型号作为先修条件。AI/ML 存储选读可用合成 IO 轨迹讨论检查点与 KV-cache 访问模式，不要求云账号、GPU 或实际训练任务。
2. **容器层（选修）：**用固定镜像运行数据库/对象存储/单机模拟集群；记录 CPU、内存和磁盘限制，实验后清理 volume。
3. **设备/集群层（选修）：**SPDK 直通 NVMe、Ceph 多节点或 Kubernetes 环境须单独说明前置硬件、网络、权限和销毁成本，并提供不依赖该环境的替代实验。

## 安全检查清单

- [ ] 任何破坏性命令均使用专用虚拟盘或临时文件系统，并逐项核对设备路径；绝不对宿主机系统盘操作。
- [ ] 不默认以 root 执行课程程序；需要特权的实验注明最小权限和恢复办法。
- [ ] 不把未经认证的管理端口暴露到公网；演示凭据不得写入代码库。
- [ ] 明确数据目录和容器卷的位置；实验结束提供清理命令及数据备份提醒。
- [ ] 对真实硬件/集群实验提供“不参与该操作”的替代路径。

## 发布前验证记录

对每个实验保存：源码 tag/commit/课程版本、执行命令、预期输出、实际结果、机器规格、错误与已知限制。对象存储实验额外记录目标服务和 API 兼容边界；集群实验记录发行版、完整镜像 digest、软件包快照及是否仅用于单机测试。更新版本后重新验证受影响的构建、API、输出和安全说明；性能数据不得跨硬件直接比较。

# 课程地图

主规划见 [课程规划.md](../课程规划.md)。课程设计共 34 课；M00–M15 的 34 篇课文与模块 README 均已完成。学习顺序以 M00–M15 为主；M04、M09、M13 的真实设备/集群实验及 M11 TiUP Playground 可选，M10 使用纯本地确定性 Raft 模拟器，M11 使用纯本地事务/MVCC 模拟器，M13 使用 localhost 日志与合成观测 demo，M15 用本机 MiniStore/临时目录/本地负载完成综合验收。**文档课文完成不等于所有候选软件栈均集成验证**：外部软件、指定发行版、真实设备、云和 Kubernetes/CSI 只按模块记录的实测状态标记；必做概念和本地实验不依赖它们。

全课必做实验默认本地运行，不要求第三方云账号或托管服务：M08 必做路径用 MiniStore 自带客户端测试其有限本地对象 API，Ceph RGW/AWS CLI 只作可选本地互操作，不连接 AWS S3；M09 必做是本地故障域/副本/重建模拟，真实 Ceph 部署纯选做；M10 必做是本地确定性 Raft 状态机模拟及标准库测试，不启动 etcd/网络集群；M11 必做是本地 MVCC/事务恢复模拟及标准库测试；TiUP Playground 仅选修且必须显式固定 v8.5.8；M13 必做使用 loopback 日志、合成 metrics/trace 与本地故障模拟，Rook/Ceph CSI 集群练习仅在隔离本地 VM 选修并使用候选锁定版本；M14 必做使用 Python 标准库在脚本自建临时目录检查权限/输入/校验/错误路径；M15 仅用 MiniStore 自建临时目录、本机 CLI、进程级故障和本地负载报告。上述必做实验均无网络、用户数据路径或裸盘参数。外网服务仅用于自愿产品对照；准备阶段可缓存依赖和镜像。多 VM 共用一台物理机的结果不作为真实高可用或硬件性能证明。

Ceph、S3 兼容服务和 FastDFS 均按目标版本与官方资料核对；课程强调接口和产品保证的边界，并将 FastDFS 作为专用文件服务案例。

课程结构参考 Harvard CS2640、CMU 18-746、CUHK CSCI5550 与 UIUC CS598 RAP 等同类课程的跨层主题、项目里程碑和研究专题组织方式；它们的层级与定位各不相同，详细链接及吸收点见[课程规划的对标说明](../课程规划.md#同类课程对标与本规划吸收点)。

每个模块目录承载总览和分课文档；每个实验独立放入 `labs/`，并在对应课文中链接。课文编号采用 `Mxx-Lyy`，实验编号采用 `lab-xx`，避免沿用来源课程编号造成混淆。
